# openRMS Rigs profiles

`profiles.json` is profile data from openRMS Rigs (commit `3109145`), by **openRMS Rigs contributors**, licensed under
the Creative Commons Attribution-ShareAlike 4.0 International licence (CC-BY-SA-4.0,
https://creativecommons.org/licenses/by-sa/4.0/). It is not covered by hamstack's own licence.

It is an adaptation: `scripts/bundle-radio-profiles.py` keeps the settings, their notes, confidence and source ids,
and each source's title, link and date. It leaves out authors' names and callsigns, sentences of notes that name
them, and links to personal sites, because hamstack's repository holds no real person's callsign. The full profiles,
with every source credited, are on the openRMS Rigs site. Changes to this data are shared under the same licence.
